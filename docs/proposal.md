# 企画書: ベランダでプチトマトエージェントIoT計画

作成日: 2026-05-28

## 目的

ベランダで育てるプチトマトに対して、土壌水分を見ながら短時間だけ給水できる小型 IoT システムを作る。

初期フェーズでは「自動栽培」ではなく、以下を実証する。

- 屋外で 100V から 5V USB-C を安全寄りに取り出せる。
- M5StickS3 と TypeC2Grove を防滴ボックス内で安定稼働できる。
- Unit Watering を短時間だけ駆動して、水やり制御の最小単位を確認できる。
- 電源、湿気、結露、ケーブル引き込み、水タンク位置のリスクを見える化できる。

## コンセプト

「プチトマトエージェント」は、最初は水分センサーとポンプ制御だけを担当する小さな栽培補助エージェントとして扱う。

将来的には、温湿度、気圧、カメラ画像、天気予報、通知、栽培ログを組み合わせる。ただし最初から全機能を入れると故障点が増えるため、電源と防滴を先に固める。

## 基本構成

| 領域 | 役割 | 主な部品 |
|---|---|---|
| 100V安全 | 防雨形コンセントから安全寄りに電源を取る | 漏電遮断器付き防雨型延長コード |
| 100V保護 | 100V接続部とUSB-C ACアダプタを雨から守る | 屋外用電源ボックス |
| 5V配線 | 100V側からM5側へ低電圧で引き回す | USB-Cケーブル |
| M5保護 | 制御本体と外部給電ユニットを湿気から守る | IP65防滴ボックス |
| 鉢側 | 土壌水分検出と給水 | Unit Watering |

## 配置方針

- 100V 側ボックスは床直置きしない。
- M5 側ボックスは水タンク、鉢皿、給水チューブより高い位置に置く。
- Unit Watering は鉢側に出すが、コネクタとケーブル出口は雨が溜まりにくい向きにする。
- 100V 側と給水チューブを近づけない。
- USB-C と Grove ケーブルは、入口直前で一度下げる水切りループを作る。

## 最初の検証手順

1. 室内で M5StickS3、TypeC2Grove、Unit Watering の単体動作を確認する。
2. USB-C 電圧・電流チェッカーで、待機時とポンプ駆動時の電圧降下を測る。
3. Unit Watering を水なしで長時間動かさず、最初は 1 秒から 3 秒の短時間に制限する。
4. 初回の吸水元はコップでもよいが、室内・短時間・手で止められる状態に限る。
5. Unit Watering の測定板を土に挿し、チューブは水源から吸って鉢へ吐く向きで固定する。
6. 屋外用電源ボックスと IP65 防滴ボックスに実物を仮配置し、曲げ半径、発熱、通線を確認する。
7. ベランダに仮設置し、雨が当たらない日中に短時間テストする。
8. 夜間、雨天、留守中の無人運転は、ログと安全停止条件を確認してから検討する。

## センサーと水源

Unit Watering U101 は、土壌水分の測定板とポンプを一体化したユニットとして扱う。最初のフェーズでは追加の土壌水分センサーを買わず、U101 単体で水分値とポンプ駆動を確認する。

水源は、室内の 1-3 秒テストならコップでよい。ただし、コップは倒れやすく、蒸発や空運転にも弱いので、ベランダ運用では 5L 級の安定した水タンクへ切り替える。

## 成功条件

- M5StickS3 が 24 時間以上再起動せずに動く。
- ポンプを 3 秒駆動しても M5 側の電圧が不安定にならない。
- ボックス内部に目視できる水滴や結露が増えない。
- ケーブル出口に水が伝って入る経路がない。
- 手動停止、電源遮断、ポンプ停止をすぐ実行できる。

## 後回しにするもの

- カメラ監視
- 外気温湿度センサーの屋外露出
- 天気API連携
- LLMによる栽培コメント
- 完全自動の長期運転

これらは魅力的だが、最初の故障点を増やすため、電源・防滴・給水の安定後に追加する。

## 未確定事項

- 実際に購入する各商品の現行仕様、寸法、付属品。
- ベランダのコンセント位置、雨の吹き込み、水はけ。
- 管理規約上、屋外電源ボックスや水タンクを常設できるか。
- Unit Watering のチューブ取り回しと水タンク容量。
- 夏季のボックス内温度上昇。
