# 安全チェックリスト

この計画では、屋外電源、水、土、ポンプを同時に扱います。チェックリストを満たすまで、長時間運転や留守中運転はしません。

## 購入前

- [ ] 100V 側の延長コードが屋外用・防雨型である。
- [ ] 漏電遮断器付きで、定格と保護機能を確認した。
- [ ] 100V 側のボックスに、延長コードのメス側と USB-C AC アダプタが無理なく入る。
- [ ] USB-C AC アダプタの PSE 表記、出力、発熱条件を確認した。
- [ ] M5 側ボックスには 100V を入れない設計になっている。
- [ ] ケーブル入口に使う部品の適合ケーブル径と取付穴径を確認した。

## 組み立て前

- [ ] 100V 配線を切らない、剥かない、加工しない。
- [ ] ケーブルに水切りループを作れる長さがある。
- [ ] ボックスの穴あけ位置が下面または側面下寄りになっている。
- [ ] ケーブル固定でコネクタに引っ張り荷重がかからない。
- [ ] 乾燥剤を電子基板から離して置ける。
- [ ] ボックス内の発熱部品に密着物がない。

## 初回通電

- [ ] 室内で M5StickS3 が起動する。
- [ ] TypeC2Grove 経由で Unit Watering が認識・制御できる。
- [ ] ポンプ駆動を 1 秒から始める。
- [ ] USB-C 電圧・電流チェッカーで待機時と駆動時を測る。
- [ ] ポンプを 3 秒動かしても M5 が再起動しない。
- [ ] 水漏れ、異音、発熱、焦げ臭さがない。

## 屋外仮設置

- [ ] 100V 側ボックスを床直置きしていない。
- [ ] M5 側ボックスを水タンクや鉢皿より高い位置に置いた。
- [ ] 給水チューブと 100V 側を離した。
- [ ] ケーブルが踏まれない、挟まれない、引っ張られない。
- [ ] 雨が直接吹き込む向きではない。
- [ ] すぐ手動で電源を抜ける。

## 運用前

- [ ] 24時間の待機テストを通した。
- [ ] ボックス内に水滴や結露がない。
- [ ] ログで再起動や通信断を確認できる。
- [ ] ポンプ駆動時間の上限を設定した。
- [ ] 水タンク空運転を避ける運用ルールがある。
- [ ] 留守中運転をしない段階か、停止条件を明文化した。

## 迷ったら停止する条件

- ボックス内に水滴がある。
- AC アダプタやケーブルが熱い。
- M5 が再起動を繰り返す。
- ポンプが空回りしている。
- ベランダ床に想定外の水が溜まる。
- 風雨が強い。
