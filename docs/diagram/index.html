この図の見方: ベランダ常設の本命は「DFRobot SEN0308級の防水土壌水分センサー + 分離チューブポンプ」。プロトタイプ部品は構成図から外しました。

配置ルール: 壁や手すりに固定できる前提にしない。M5側防滴ボックスは、横長プランターに立てた短い支柱/小型ワイヤーネットへ結束バンドで固定する。

環境情報も取るなら: ENV IIIで温度・湿度・気圧、DLightで照度を追加。G9/G10はI2Cに使い、土壌水分はUnit ADC、ポンプ制御はEXT.IO2へ逃がす。

センサー保護: ENV IIIやDLightは裸で雨ざらしにしない。外気用には小型百葉箱/自然通風シェルター、照度用には透明カバーを別途用意する。

具体候補: ENV IIIはフィールドプロFP1806級の小型自然通風シェルター、DLightは透明フタ付き小型ケースを候補にする。百葉箱にDLightを入れると暗く測る。

実例傾向: 屋外DIYでは、温湿度は放射シールド/Stevenson screenに入れる。既製品を買う、3Dプリントする、白い皿状パーツで自作する、の3パターンが多い。

簡単案: 屋外温湿度はSwitchBot防水温湿度計に任せる。照度/UVまで欲しいならEcowitt系のWi-Fi気象センサーを別系統で使う。M5は土壌水分とポンプ制御に集中。

コスト感: SwitchBot防水温湿度計のみ約2,000円、Hub込み約7,500〜8,000円。Ecowitt照度込みは約20,000円前後から。M5直結DIYは保護部品込みで約8,000〜25,000円以上。

照度は必須: 北向きで何が育つかを決める入口。まずスマホ照度アプリか安価な照度計で朝/昼/夕方のluxを測る。常時IoT化はその後でよい。

M5箱の固定

ラック前提にしない。プランターの土に短い支柱か小型ワイヤーネットを立て、箱を結束バンドで固定する。

温湿度・照度

簡単案はSwitchBot防水温湿度計。照度/UVまで欲しいならEcowitt系。ENV III/DLightはM5直結DIY案として残す。

コスト比較

推奨はSwitchBot + Hubで約7,500〜8,000円。照度込みEcowittは約20,000円前後から。

照度の初期調査

後回しにしない。スマホ照度アプリか安価な照度計で、朝/昼/夕方の明るさを先に測る。

北向きベランダ

大葉は明るい半日陰が候補。暗い場合は徒長するので、置き場所を明るい側へ寄せるか育成ライト補助を検討。
