## 北向きベランダの栽培注意

ミニトマトは日光を強く必要とする。北向きで直射日光がほとんどない場合、実つき、甘さ、株の強さはかなり不利。育てるなら以下のどれかを前提にする。

- 直射日光が1日4-6時間以上入る場所へ置ける。
- 反射光が強く、午前/午後のどこかで直射が入る。
- 植物育成ライトを補助する。
- 収穫量は少なめと割り切り、ミニトマトより葉物・ハーブへ切り替える。

## 購入前チェック

- 型番が一致しているか。
- 屋外用、防雨、防滴、防塵の表記が用途に合うか。
- PSE や定格が確認できるか。
- 実物寸法がボックス内寸に収まるか。
- USB-C コネクタがセパレートキャプコンを通せるか。
- 密閉に近い箱内で AC アダプタが過熱しないか。
- ベランダに露出するセンサーやポンプに、防水等級または屋外利用前提の説明があるか。
