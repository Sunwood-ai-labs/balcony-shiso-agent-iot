# 屋外運用設計

作成日: 2026-05-28

## 結論

ベランダで常設するなら、M5Stack Unit Watering U101 を雨ざらし前提の本命部品にしない。

U101 は土壌水分の測定板とポンプが一体で便利だが、公式仕様上、IP65/IP67 などの屋外防水等級は確認できない。したがって、屋外常設の本命構成は以下へ切り替える。

```text
M5側IP65ボックス
  ├ M5StickS3
  ├ TypeC2Grove / Grove変換
  ├ ポンプ駆動回路
  └ 必要なら小型5Vポンプ

鉢側
  ├ IP65/IP68級の土壌水分センサー
  ├ 給水チューブ
  └ 不織布ポット

水源
  └ 倒れにくい5L級タンク
```

## Unit Watering の扱い

| 用途 | 判定 | 理由 |
|---|---|---|
| 室内1-3秒テスト | OK | 手で止められ、水濡れをすぐ確認できる |
| ベランダの軒下・短時間テスト | 条件付き | 雨が当たらず、撤収できる場合のみ |
| 雨ざらし常設 | NG | 防水等級が確認できない |
| 本命屋外運用 | 非推奨 | 基板、Groveコネクタ、ポンプ本体の保護が不十分 |

## 本命候補

### 土壌水分センサー

屋外常設するなら、防水等級が明記された土壌水分センサーを選ぶ。

- DFRobot Gravity IP65 Capacitive Soil Moisture Sensor / SEN0308
  - IP65、防水保護、屋外ガーデニング向けの説明あり。
  - Arduino / ESP32 / Raspberry Pi 向けのアナログセンサーとして扱える。
- IP68級アナログ土壌水分センサー
  - 価格は上がるが、埋設や屋外環境を前提にしやすい。

### ポンプ

ポンプはセンサーと分離する。

- ポンプ本体をM5側防滴ボックス内、または雨が直接当たらない小型ポンプ箱へ置く。
- 水に触れるのはチューブだけにする。
- 空運転を避けるため、1回の駆動時間、1日の回数、水源残量確認を必須にする。

## 構成の考え方

U101一体型は「早く試す」には便利だが、「ベランダ常設」には部品の屋外耐性が足りない。屋外本命では、濡れてよい部品と濡らしてはいけない部品を分ける。

| 場所 | 外に出してよいもの | 保護するもの |
|---|---|---|
| 土の中 | 防水土壌水分センサーのプローブ部 | センサー基板が露出する製品は避ける |
| 鉢まわり | 給水チューブ、吐水口 | Groveコネクタ、裸基板 |
| M5箱 | M5StickS3、TypeC2Grove、駆動回路 | 100Vは入れない |
| 水源 | 5L級タンク、吸水チューブ | コップ常設は避ける |

## 直近の判断

1. ベランダ常設を最初から狙うため、防水土壌水分センサーとポンプ分離構成を買う。
2. U101 は購入優先度を下げる。買う場合も室内/軒下プロトタイプ扱いにする。
3. 構成図にはU101を載せず、本命構成だけを載せる。
