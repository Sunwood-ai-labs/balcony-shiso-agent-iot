# ベランダで大葉エージェントIoT計画 02

100V 側と 5V 側を分離した、ベランダ用大葉 IoT 給水構成の寸法検討フォルダです。

## 成果物

- `docs/research.md` - 寸法調査、採用値、未確定点
- `forgecad/main.forge.js` - 100Vボックス、5Vボックス、機器配置、水切りループの3Dブロック図

## 結論

ForgeCAD で図面化できます。今回の段階では、購入前検討用の「寸法ブロック図」として作るのが適切です。

100V 側の完成品を分解・加工しない前提なので、CAD で作るべきものは電気部品そのものではなく、以下の確認図です。

- 屋外用電源ボックス内に HATAYA BFX 系と USB-C ACアダプタを余裕を持って置けるか
- 5V 側ボックス内に M5StickS3、TypeC2Grove、MOSFET、GND端子台、乾燥剤が入るか
- USB-C ケーブルと Grove ケーブルに無理な曲げが出ないか
- ケーブル入口を下側/下寄りにして水切りループを作れるか
- 100V 側と水やりチューブを離せるか

## 安全境界

- 100V 側は完成品を挿すだけ。
- 100V 配線を切らない、剥かない、ねじらない、加工しない。
- IP65 防滴ボックスには 100V を入れない。
- 屋外・水回り・電源の組み合わせなので、最終設置前に製品説明書と電気工事士/有資格者相当の確認を優先する。

## 次に実測するもの

- HATAYA BFX-013KC2 のブレーカーボックス部と3口タップ部の外形
- 実際に使う USB-C ACアダプタのサイズと発熱条件
- 採用する IP65 ボックスの有効内寸、内部リブ、取付ボス位置
- ケーブルグランド径とUSB-Cコネクタが通るか
